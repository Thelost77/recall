# recall v0.4.0

This release changes the default embedding model to EmbeddingGemma and removes Grok Build support.
It also skips each harness whose CLI is not installed.

## Breaking changes

- The default embedding model is now `embeddinggemma-2:270m`, and the default semantic threshold is now `0.80`.
- `recall` accepts only EmbeddingGemma models. With another model, such as `all-minilm`, each command that uses the embedding model fails. Search with `--lexical-only` still works.
- Grok Build support is removed. `--harness grok` fails, and `recall index` deletes the indexed Grok sessions.

## Changes

- Add the EmbeddingGemma prompt prefixes to queries and documents.
- Use a harness in `recall index` and `recall doctor` only when its CLI is on `PATH`. A skipped harness keeps its indexed sessions.
- Treat a missing session directory or OpenCode database as no sessions, not as an error.
- Show an empty resume command for a result from an unknown harness.

## Upgrade

Do these steps:

1. Make sure that Ollama is version 0.40.4 or later.
2. Pull the new model:

   ```sh
   ollama pull embeddinggemma-2:270m
   ```

3. If your config sets `embedding.model` to a model that is not EmbeddingGemma, remove `embedding.model` and `embedding.threshold`.
4. Use `recall index` to embed all chunks and memories again.

EmbeddingGemma is slower than `all-minilm`, so the first index after the upgrade can take a long time.
Until it is complete, semantic search finds no sessions. Lexical search still works.

If a systemd timer runs `recall index`, make sure that the CLI of each harness is on the `PATH` of the service.

## Installation

Install or update `recall`:

```sh
go install github.com/Thelost77/recall/cmd/recall@v0.4.0
```
