# recall v0.2.0

First release after merging unified local recall and renaming the repository.

## Highlights

- New `recall` CLI: search sessions and explicit durable memories together
- Canonical memories as versioned JSON; disposable SQLite memory index
- Explicit memory commands: `remember`, `edit`, `forget`, `restore`, `list`, `show`, `history`
- Syncthing conflict detection without auto-merging conflict copies
- `agent-sessions` remains available as a compatibility binary

## Repository rename

The GitHub repository and Go module path are now `github.com/Thelost77/recall`.
Existing session indexes and `~/.config/agent-sessions` configs continue to work.
Prefer `~/.config/recall/config.toml` for new setups.

## Installation

```sh
go install github.com/Thelost77/recall/cmd/recall@v0.2.0
go install github.com/Thelost77/recall/cmd/agent-sessions@v0.2.0
```

Or:

```sh
git clone https://github.com/Thelost77/recall.git
cd recall
make install
```

If you previously installed the systemd timer, switch to the renamed units:

```sh
cp contrib/systemd/recall-index.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now recall-index.timer
```
