# recall v0.3.0

This release indexes Grok Build sessions.

## Changes

- Add a `grok` harness, enabled by default.
- Read `~/.grok/sessions/<encoded-cwd>/<session-id>/updates.jsonl`.
- Take the title, working directory, branch, git remote, parent session, and timestamps from `summary.json`.
- Resume a result with `grok --resume <session-id>`.
- Use `$GROK_HOME/sessions` when `GROK_HOME` is set and `sources.grok` is unset.

## Installation

Install or update `recall`:

```sh
go install github.com/Thelost77/recall/cmd/recall@v0.3.0
```
