# recall v0.2.1

This patch release fixes Claude Code session indexing.

## Changes

- Index command-only Claude sessions instead of reporting a missing session ID.
- Preserve session paths, branches, and time bounds from non-message records.
- Add regression coverage for command-only Claude session files.

## Installation

Install or update `recall`:

```sh
go install github.com/Thelost77/recall/cmd/recall@v0.2.1
```
